**Author:** gabe

## Visual Theme
- 90s Windows XP aesthetic (classic teal/green color palette, pixelated icons, default system fonts).
- Inspired by a warehouse/mail‑sorting center UI: grid‑based layouts, list views for items, clear status indicators, and tactile interaction cues.

## Design Goals
- Provide a nostalgic, familiar interface that feels like navigating a retro desktop while managing warehouse logistics.
- Ensure high contrast and accessibility (large clickable areas, keyboard navigation) to match the “mail sorting” workflow.
